# 飞鸟 Asuka

**Windows 桌面表情包管理器 —— 为 PC QQ 而生，不止于 QQ**

[English](README.en.md) | 简体中文

`WPF` `.NET 10` `Windows 10/11` `v1.0.0`

</div>

---

飞鸟（Asuka）把散落在 QQ 收藏、聊天记录、浏览器里的表情图片收进一个本地图库：
打标签、按热度排序、GIF 悬浮预览，然后**在任意应用里一键发送**。
发送走系统剪贴板 + 模拟粘贴，零注入、零封号风险，原画质与动图完整保留。

针对 PC 版 QQ（NTQQ）深度适配：点开 QQ 自带表情面板时，飞鸟会自动在旁边弹出快捷面板，
两边并排、点完即关，体验如同原生功能。任何接受粘贴图片的软件（微信、TIM、浏览器、Office…）
都可以通过全局热键唤起快捷面板直接发送。

## 🚀 快速使用

1. **下载运行**：到 [Releases](../../releases) 下载 `Asuka.zip`，解压后运行 `Asuka.exe`（需 [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0) x64，详见下文安装）
2. **导入表情**：把表情图片或整个文件夹拖进窗口，批量打好标签
3. **发送**：在聊天输入框按 `Ctrl+Alt+D` 唤出快捷面板，点击表情即自动粘贴发送
4. **进阶**：在 设置 → QQ 联动 中绑定 QQ 账号同步收藏表情；在任意应用里「复制图片」可一键入库

到第 3 步就已经能用了，往下是完整的功能与设置说明。

## 📦 安装

### 下载成品（推荐）

到 [Releases](../../releases) 下载最新版 `Asuka.zip`，解压后运行 `Asuka.exe`。

> 单文件发布，需要安装 [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0)（x64）。

### 从源码构建

```bash
git clone https://github.com/lorinatsureborn/OICQStickerManager.git
cd OICQStickerManager
dotnet build -c Release
# 产物在 bin/Release/net10.0-windows/
```

需要 Windows 10/11 + .NET 10 SDK（含桌面工作负载）。发布单文件：

```bash
dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o publish
```

## ✨ 关键特性

### 图库管理
- **拖放入库**：文件或整个文件夹拖进窗口即完成导入，自动弹批量标签编辑器
- **智能导入**：内容 MD5 去重、魔数嗅探修正错误扩展名、WebP 自动转码为 PNG
- **标签体系**：多标签、标签池点选、按标签筛选，悬浮表情实时显示所属标签
- **热度排序**：频次 × 新近度（frecency）排序，常用的表情永远在最前面；「最近」页随时兜底
- **GIF 悬浮预览**：静态网格 + 角标，悬浮 400ms 弹出动图气泡，滚动不卡、内存不涨

### 快速发送
- **快捷面板**：全局热键（默认 `Ctrl+Alt+D`）随时唤起，非激活窗口，不抢聊天焦点
- **点一下就到**：点击表情 → 自动粘贴到当前聊天输入框，面板自动收起
- **胶囊标签页**：面板内悬浮切标签，150ms 意图延迟防误触，每次呼出复位「全部」
- **单击 / 双击可选**，双击模式内置系统级去抖，快速双击不会发出两张
- **剪贴板善后**：发送后自动恢复原剪贴板内容；也可关闭，让表情留在剪贴板方便连发

### QQ 联动（零注入）
- **表情面板共存**：点 QQ 聊天窗的「表情」按钮，QQ 原生面板与飞鸟快捷面板并排弹出；
  关闭 QQ 面板，飞鸟面板跟随收起；发送时两边一起关，不留残留状态
- **收藏表情镜像**：绑定 QQ 账号后，图库出现「QQ（别名）」页 = 你 QQ「爱心分页」的活镜像，
  增删实时同步；页面里可直接发送（零拷贝），也可右键收编进图库
- **多账号绑定**：支持同时绑定多个 QQ 号，软件只询问、绝不擅自绑定
- **「添加到表情」联动**：在 QQ 里右键图片点「添加到表情」，飞鸟感知新收藏并按设置入库
- **剪贴板捕获**：在 QQ、微信、浏览器里「复制图片」，右下角弹出提示一键入库，
  重复内容自动静默
- **深度同步（可选）**：识别「已在 QQ 取消收藏但缓存仍在」的表情并按策略处理
  （仅标记 / 同步删除 / 挪入图库）

### 界面与桌面体验
- **iOS 26 液态玻璃**：真磨砂材质、四套配色（aurora / mint / midnight / ember）运行时切换、
  磨砂浓度可调
- **托盘常驻**：关闭到托盘（首次询问并记住选择）、开机自启动、启动静默驻留、单实例
- **失败可见**：数据保存采用原子写 + 备份 + 损坏自愈，异常必弹窗提示，绝不静默丢数据

## 📖 使用详解

### 1. 导入表情

| 方式 | 操作 |
|---|---|
| 拖放 | 把图片文件 / 文件夹拖进主窗口，完成后批量打标签 |
| 复制捕获 | 在任意应用里「复制图片」→ 右下角提示 → 点击入库 |
| QQ 收藏联动 | QQ 里右键图片 →「添加到表情」，飞鸟按设置自动入库 |

导入自动完成：内容去重（MD5）、格式修正（按文件头而非扩展名）、WebP 转 PNG。

### 2. 整理与查找

- 左侧标签列表筛选，搜索框全局搜索标签；搜索时点标签胶囊可快速切换搜索词
- 默认「最近」视图按热度排序：越常用、越近期用过的排越前
- 悬浮任意表情可预览动图、查看标签；右键可编辑标签、删除、打开所在文件夹

### 3. 发送表情

<div align="center">
<img src="docs/images/quick-panel.png" width="560" alt="快捷表情面板" />
</div>

**快捷面板（推荐）**：在聊天输入框按 `Ctrl+Alt+D` → 面板在光标旁弹出 → 点击表情 →
自动粘贴进输入框，面板收起。全程焦点不离开聊天窗口。
面板顶部胶囊可悬浮切换标签；🔍 按钮跳转主窗口搜索。

**主窗口**：单击（或双击，可在设置选择）表情 → 主窗口自动最小化并粘贴到之前的窗口。

**QQ 共存模式**：点 QQ 聊天窗的「表情」按钮 → QQ 原生面板弹出时飞鸟面板自动在旁边出现 →
点飞鸟里的表情直接进输入框，两边面板同时收起。全程无需热键。

> 发送原理：写入系统剪贴板（文件 DropList）+ 模拟 `Ctrl+V`——这是唯一能完整保留
> GIF 动图与原画质、且对目标应用零注入的通道。发送后原剪贴板内容 1 秒内恢复。

## ⚙️ 设置说明

<div align="center">
<img src="docs/images/settings.png" width="560" alt="设置" />
</div>

设置入口在主窗口左下角。

**通用**
| 设置 | 说明 |
|---|---|
| 开机自启动 | 登录 Windows 后自动启动飞鸟 |
| 关闭时最小化到托盘 | 开启后点 ✕ 隐藏到托盘，从托盘图标退出程序；首次点 ✕ 会询问并记住选择 |
| 启动时进入托盘 | 启动不显示主窗口，直接驻留托盘（配合自启动使用） |

**外观**
| 设置 | 说明 |
|---|---|
| 主题配色 | aurora / mint / midnight / ember 四套配色，切换即时生效 |
| 磨砂浓度 | 玻璃材质的白度与不透明程度（50–100%），实时预览 |

**发送**
| 设置 | 说明 |
|---|---|
| 单击 / 双击发送 | 图库点击方式；双击模式对系统双击时限内的重复点击去抖 |
| 发送后恢复剪贴板 | 默认开：发送后恢复你原来的剪贴板内容；关闭时，表情发送后会留在剪贴板 |

**快捷键**
| 设置 | 说明 |
|---|---|
| 呼出快捷面板 | 默认 `Ctrl+Alt+D`。点击捕获框后按下新组合键即可更换（Esc 取消），可恢复默认 |

**QQ 联动**
| 设置 | 说明 |
|---|---|
| 绑定 QQ 表情… | 扫描本机 QQ 账号，多选绑定 / 解绑；每个绑定一个「QQ（别名）」选项卡 |
| QQ 表情面板共存 | 点开 QQ 表情面板时，自动在旁边弹出快捷面板 |
| 轮询保底 | 推荐快捷面板弹出异常时开启；开启后会定期查询 QQ 的表情面板状态，保证联动不失效，对性能影响很小 |
| QQ 新收藏自动入库 | 在 QQ 里点「添加到表情」后，自动复制进图库并打「QQ」标签；关闭则不自动导入 |
| QQ 收藏深度同步 | 推荐想自动识别「已在 QQ 取消收藏的表情」时开启；开启时会引导你用官方工具读取一次收藏索引来保证识别准确，仅需登录一次。开启后可选择发现已取消收藏的表情时的处理方式：仅标记 / 同步删除 / 挪入图库 |

**图库 / 资源库**
| 设置 | 说明 |
|---|---|
| GIF 悬浮预览 | 悬浮表情时自动播放动图气泡 |
| 复制图片后提示入库 | 在 QQ、浏览器等任意应用里「复制图片」后，右下角弹出一键入库提示 |
| 提示停留时长 | 入库轻提示的停留秒数（3–15，默认 8），超时未处理视为忽略并自动消失 |
| WebP 图片支持 | 显示系统 WebP 解码支持状态；未安装时可跳转微软商店安装「WebP 图像扩展」，支持重新检测 |
| 打开表情存放文件夹 | 直接打开本地图库目录 |

**数据位置**：所有数据都在 `文档\OICQStickerManager\`（`Library` 图片库 + `stickers.json` 标签
+ `config.json` 配置），备份 / 迁移拷走整个文件夹即可。

## 🔒 隐私与安全

- 表情与配置**全部存本机**，核心功能**零网络行为**、**零注入**——不修改 QQ 任何文件与内存；
- QQ 联动基于只读文件系统监视与 Windows UI 自动化（纯只读感知），与 QQ 官方功能并行不悖；
- 深度同步（默认关）是唯一的例外：开启时会从 GitHub 下载第三方开源脚本
  [QQBackup/qq-win-db-key](https://github.com/QQBackup/qq-win-db-key) 读取一次收藏索引，
  密钥只保存在本机。全过程只读，不注入、不写入 QQ，失败自动降级、不影响其他功能。

## ⚠️ 已知限制

- 仅支持 Windows 10/11（x64）；
- 动画 WebP 无法入库显示（会转成静态 PNG）；GIF 完整支持；
- 快捷面板是非激活窗口（不抢聊天焦点），因此面板内没有搜索框，🔍 会跳转主窗口搜索；
- 微信等无 UI 自动化联动的应用，请使用全局热键唤出快捷面板；
- QQ 大版本更新可能导致共存联动失灵，属良性降级——开启「轮询保底」即可恢复。
